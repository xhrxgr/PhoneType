# PhoneType

[English](README_en.md) | [简体中文](README.md)

PhoneType 把手机上输入的文字转发到同一局域网内 Windows 电脑的当前焦点窗口。手机相当于一块键盘：
在手机上输入或通过语音识别出的文字，会插入到电脑上光标所在的位置。

手机页面是一个纯输入界面，没有可见的编辑框。点按触发区会唤起手机键盘（含系统自带的语音输入），
只读区域显示最近一次发送的文字，便于核对。

## 工作原理

- 电脑上运行的本地服务通过 HTTP（端口 8765）提供静态页面，并通过 WebSocket（端口 8766）接收连接。
- 手机在同一网络的浏览器中打开该页面，只把每次编辑的增量变化发送给电脑。
- 电脑端服务通过 Windows `SendInput` API，以 Unicode 键盘事件把文字插入到当前光标处，
  不会选中或替换输入框中已有的内容。

## 功能

电脑端（Windows）：

- 以系统托盘图标运行，无控制台窗口。
- 连接信息窗口：列出局域网地址与二维码，可用下拉框选择二维码对应的地址，每个地址带复制按钮。
- 开机自启动开关（在 `HKCU\...\Run` 中添加或删除启动项）。设为自启动后，
  **开机时静默进入托盘**，不会弹出连接信息窗口；手动启动（快捷方式 / 开始菜单）仍会弹出。
  自启动项会带上 `--startup` 参数，旧版本写入的项会在下次启动时自动补上。
- 单实例：再次运行会把已运行的窗口提到前台，不会重复开窗或争抢端口。
- 「关于」窗口显示版本号。

手机端（任意手机浏览器）：

- 无需安装 App，打开网页即可使用。
- 使用手机自带键盘与语音输入，识别结果以纯文本转发。
- 快捷键：方向键 / Home / End / Delete / Tab / Esc / Enter，以及 Ctrl 组合
  （全选 / 复制 / 粘贴 / 剪切 / 撤销）与退格键。
- 清空按钮：只清空电脑上焦点输入框的内容，不会发送回车。

文本插入：

- 通过 `SendInput` 插入到光标处，支持中文、英文与换行。目标程序无需做任何修改。

## 架构

```
手机浏览器 (www/index.html) --WebSocket 8766--> 电脑服务 (server.py) --SendInput--> 焦点窗口
手机浏览器  <--HTTP 8765 提供页面--
```

## 安装

### Windows（推荐，使用安装器）

从 Releases 页面下载 `PhoneTypeSetup.exe` 并运行，点击「安装」。安装器会：

- 安装到 `%LOCALAPPDATA%\Programs\PhoneType`（装在用户目录，**不需要管理员权限**）
- 创建开始菜单快捷方式
- 在「添加或删除程序」中注册，可随时卸载

如果 PhoneType 正在运行，安装器会**先自动关闭它**再继续安装。

再次运行安装器可以：

- **更新**：检测到已安装版本较旧时，按钮变为「更新到 x.x.x」
- **重装**：版本相同时覆盖安装一次
- **卸载**：关闭运行中的程序，并清除安装目录、快捷方式、注册表项（含开机自启动项）

命令行参数：

```
PhoneTypeSetup.exe /SILENT            静默安装或更新
PhoneTypeSetup.exe /uninstall         卸载（弹确认框）
PhoneTypeSetup.exe /uninstall /SILENT 静默卸载
```

静默模式的执行日志写在 `%TEMP%\PhoneType_setup.log`。

### 便携版（免安装）

从 Releases 页面下载 `PhoneType.exe`，放到任意目录直接运行。它同样是独立可执行文件
（已内置 Python 与依赖），但不写注册表、不创建快捷方式，删掉文件即为卸载。

### 从源码运行

需要 Windows 上的 Python 3.10 或更高版本。

```bash
pip install -r requirements.txt
python tray_app.py     # 托盘版（推荐）
# 或
python server.py       # 控制台版，会在终端打印地址
```

## 使用方法

1. 在电脑上启动 PhoneType，连接信息窗口会列出局域网地址和二维码。
2. 手机连接到同一 Wi-Fi，打开 `http://<电脑IP>:8765/`，或扫描二维码。
3. 点击电脑上要输入的目标窗口，使其获得焦点。
4. 点按手机页面的触发区唤起键盘，然后输入或说话，文字会插入到电脑光标处。

如果扫码连不上，可在下拉框中换一个地址重试。

回车映射（手机页面右上角的下拉框，默认 `Enter`）决定手机键盘按下回车时，电脑收到哪个组合键：

- `Enter`（默认）：会触发发送 / 提交。
- `Shift+Enter`：在多数聊天软件里是换行，不会因为误触把消息发出去。
- `Ctrl+Enter`
- `Alt+Enter`

## 输入模型

手机页面使用一个隐藏输入框作为输入法载体，而不是可见的编辑框，并且只发送每次编辑的增量：
新增的文字在电脑光标处输入，删除则转发为光标处的退格键。载体的整体重置不会发送任何按键，
以免误删电脑上的内容——需要清空电脑输入框时请使用清空按钮。

电脑焦点输入框中已有的文字会保持不变，手机输入从当前光标处继续。

## 限制

- 仅支持 Windows（输入注入依赖 Windows 的 `SendInput` API）。
- 电脑与手机需处于同一网络。
- 传输是局域网内的明文 WebSocket 且没有身份验证。同一网络中知道地址的人都可以向电脑输入文字，
  因此请只在自己信任的网络中使用。
- 单向：在电脑上直接做的编辑不会回传到手机（这是为避免依赖 UI Automation 而有意设计的）。
- 从手机发出的删除会转成光标处的退格键，可能与电脑上的选区不对应。复杂编辑请直接在电脑上操作，
  或使用清空按钮。

## 源码结构

- `server.py` —— HTTP 与 WebSocket 服务、Windows 输入注入。
- `tray_app.py` —— 系统托盘宿主（复用 `server.py`）；连接信息 / 二维码、关于、开机自启动。
- `www/index.html` —— 手机端页面。
- `installer.py` —— 安装器：安装 / 更新 / 卸载，并自动关闭正在运行的实例。
- `scripts/make_icon.py` —— 重新生成应用图标（`assets/app.ico`）。
- `build_exe.bat` —— 打包主程序 `dist/PhoneType.exe`。
- `build_installer.bat` —— 打包安装器 `dist/PhoneTypeSetup.exe`（需先执行 `build_exe.bat`）。
- `requirements.txt` —— Python 依赖。

## 构建可执行文件

```bat
build_exe.bat          :: 生成 dist\PhoneType.exe（PyInstaller，单文件，无控制台）
build_installer.bat    :: 生成 dist\PhoneTypeSetup.exe（内含上面的主程序）
```
